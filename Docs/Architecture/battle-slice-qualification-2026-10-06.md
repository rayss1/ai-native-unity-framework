## 配置与方法

主机：11th Gen Intel(R) Core(TM) i7-11800H @ 2.30GHz，16 逻辑处理器，33963081728 字节物理内存；非专用 Windows 主机。两个 Battle 节点、每节点两个 worker，seed 20261002，输入 60 Hz。每阶段预热 60 秒，阶梯各测量 300 秒，soak 测量 3600 秒。

正式运行显式选择负载输入线程 AboveNormal；进程报告为 Normal，默认输入线程仍为 Normal。仅受控输入线程在启动前设定优先级，未采样动态 OS 优先级。使用 Windows 高精度等待、生产匹配的 Pooling=true；GC/输入节奏/KDF 诊断关闭，构建节点复用及共享编译关闭。发布跳过依赖漏洞审计，不能据此声称本轮执行了新的漏洞扫描。

Tick、ACK 与主机 CPU 均采用 nearest-rank 分位数；Tick 按精确去重 Tick ID 统计。物理主机约每 2 秒采样，要求覆盖完整测量窗、最大间隔 ≤5 秒，CPU P99 ≤80%、内存使用峰值 ≤80%。占用比例 ≥95%，实际测量序号窗口接受输入比例 ≥80%；零测量窗口明确排除。

## 失败保留与审核修正

此前的房间周转、输入节奏、终态连接关闭及主机 CPU 超限失败均保留，未被本次通过覆盖。sweep02 一小时尝试约 34 分钟因 Closed 中断；sweep03 的 32 人阶段输入率失败；此前 AboveNormal 128 人诊断虽完成 105 房，仍因主机 CPU P99 99% 失败。这些结果不能被独立 replay 通过改称容量通过。
