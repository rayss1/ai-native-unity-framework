# Battle slice completion plan and evidence

Authority: the owner's 2026-10-04 goal, ADR-0002/0005/0017, public API contracts and existing capacity budgets.

## Design and acceptance

Complete the existing slice: correct reusable prediction sends, fail-closed real PostgreSQL CI, measured candidate capacity, and visible interpolated remote players. Preserve fixed 60 Hz authority, existing wire fields, vendor pins, bounded memory, and source-bound replay evidence. No commit, push, external deployment, user Editor termination or unrelated cleanup is authorized by this plan.

Prediction sends use an explicit caller-owned encoded frame; async send completion and backpressure are observable. The current application's bounded input ring remains its owner. Unused unsafe convenience APIs may be replaced with a documented pre-release migration, after confirming callers. Sending never predicts a second time on retry.

Remote presentation decodes existing full snapshots into caller-owned storage and retains bounded history keyed by entity and server tick. Render behind the newest authority, interpolate position and shortest-path yaw, hold on missing future data, and snap discontinuities such as respawn. Local prediction stays separate. Remove absent players and reset history on reconnect/room change. Package code owns decoding/interpolation; Unity owns GameObjects. No new server authority or wire schema is introduced.

Database CI uses an isolated pinned PostgreSQL service, runs named persistence cases, and rejects missing discovery, failures and skips. Normal solution tests remain enabled. Capacity reuses the original eight-player/60 Hz 1/2/4-room-per-Worker sweep, 60-second warmup, 300-second measurement and 3600-second highest-passing soak, with independent replay/input/headroom checks. A failed profile is evidence to diagnose, never permission to loosen budgets.
