# Runtime acceptance candidate image

This internal-only image publishes the gated WS-16 Battle Host with the exact Fantasy package stored in the pinned submodule. CI resolves immutable .NET SDK and ASP.NET runtime image digests, builds for Linux x64, runs as the base image's non-root user, proves a real Fantasy KCP Login/Join/Input/Snapshot/Reconnect loopback and a 64-session short load, replays the accepted production Input stream, probes readiness/drain and graceful SIGTERM, and records source, Fantasy, protocol, configuration, and image identities.

The image listens on HTTP port `8080` and Fantasy KCP UDP port `22000`. `Fantasy.config` is application-owned and the published image contains exactly one default copy. Evaluation deployments can replace it without rebuilding the image by mounting a reviewed file read-only at `/app/Fantasy.config`; port and topology changes must remain consistent with the exposed UDP mapping and recorded provenance.

Set `AINATIVE_REPLAY_CAPTURE_PATH` to enable the bounded asynchronous replay log and verify the stopped log with `dotnet AiNative.BattleHost.dll --verify-replay <path>`. Set `AINATIVE_ACCEPTANCE_REPORT_PATH` and `AINATIVE_ACCEPTANCE_MAX_TICKS` to retain exact Host percentile/allocation evidence; `/admin/kcp-load` resets measurement on a room-Tick boundary after all clients join and accepts separate `warmupSeconds` and measured `durationSeconds` values. The PR workflow always runs deterministic codec-level profiles plus real 64-client Regional/Degraded Linux `tc netem` profiles. It stores qdisc statistics and a hashed PCAP, then calculates per-client one-second bandwidth and UDP payload percentiles including IPv4/UDP/KCP overhead. Applying the `qualified-soak` PR label additionally runs the real 64-session KCP load for 60 measured minutes after a ten-second warm-up and uploads the Host/load reports.

The workflow does not push or otherwise distribute this image. Legal approval, exact-final-commit Unity evidence, green exact-commit socket profiles, and a green label-gated 60-minute-after-warm-up result remain release gates. The image must not be promoted while ADR-0012 is Proposed.
